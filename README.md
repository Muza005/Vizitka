# Сайт-визитка Музаффара Азимова

Одностраничный сайт frontend-разработчика из Ташкента: визитка с QR-кодом на Telegram, проекты с галереей экранов, цены, условия работы и контакты. Три языка (русский, узбекский, английский), светлая и тёмная тема.

## Что на сайте

- Визитка в пропорциях 85×55 мм: наклоняется за курсором и по клику переворачивается на QR-код Telegram
- Лента проектов: листается колёсиком мыши, края плавно затухают, по клику открывается окно с галереей экранов; скриншот можно увеличить на весь экран
- Прайс в сумах, условия, этапы работы, контакты с кнопкой «Копировать»
- Плавная смена языка и темы (тема раскрывается кругом от кнопки через View Transitions API, в остальных браузерах цвета плавно перетекают)
- Адаптив под телефон, учёт `prefers-reduced-motion`

Без фреймворков и сборки: чистые HTML, CSS и JavaScript. Шрифты Geologica и Golos Text подключаются с Google Fonts.

## Структура

```
index.html      разметка страницы
styles.css      стили и обе темы
script.js       тексты, цены, проекты и вся логика
images/         скриншоты проектов (WebP)
favicon.svg     иконка вкладки
```

## Как поменять содержимое

Почти всё редактируется в `script.js`:

| Что | Где |
|---|---|
| Тексты интерфейса на трёх языках | объект `T` |
| Услуги и цены | объект `PRICES` |
| Что входит, что не входит, этапы работы | объект `TERMS` |
| Проекты: описания, скриншоты, ссылки на демо и код | массив `PROJECTS` |
| Пути к скриншотам | объект `IMG` |

Контакты на визитке и в блоке «Контакты» лежат в `index.html`. QR-код там же, в виде SVG-пути для `https://t.me/A_vM5`: если сменится Telegram, QR нужно сгенерировать заново.

## Запуск

Достаточно открыть `index.html` в браузере. Или поднять локальный сервер:

```bash
npx serve .
```

## Публикация

**Netlify:** Add new site → Import an existing project → GitHub → репозиторий `Vizitka`. Build command оставить пустым, Publish directory — `.`. После этого каждый push в `main` обновляет сайт сам.

**GitHub Pages:** Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`.
